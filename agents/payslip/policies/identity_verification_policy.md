# Identity Verification Policy

## 1. Employee Name

The employee name on the payslip should match the applicant's declared name.

## 2. Employee ID

If an employee ID is available, it should be consistent across submitted employment documents.

## 3. Company

The employer name shown on the payslip should be consistent with the employment information provided by the applicant.

## 4. Name Mismatch

If the applicant name does not match the employee name on the payslip, the identity verification should fail or require manual review.

## 5. Missing Identity Information

If required employee identity information is missing, the system should flag the document for review.
